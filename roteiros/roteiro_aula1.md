# Roteiro de Aula 1 — Primeiros Passos no Scratch

## Duração: 50 minutos

### Objetivos
- Conhecer a interface do Scratch
- Criar o primeiro programa
- Entender blocos básicos: movimento, aparência, eventos

### Materiais
- Computador com acesso à internet
- Acesso ao [scratch.mit.edu](https://scratch.mit.edu/)

### Passo a Passo

#### 1. Apresentação (10 min)
- O que é o Scratch?
- Mostrar a interface: palco, sprites, blocos, área de script
- Demonstrar um projeto simples funcionando

#### 2. Atividade Guiada (20 min)
1. Criar novo projeto
2. Arrastar `quando bandeira verde clicada`
3. Adicionar `mova 100 passos`
4. Testar clicando na bandeira verde
5. Adicionar `gire 15 graus`
6. Colocar dentro de `sempre` → sprite gira em círculos!
7. Personalizar: mudar sprite, cenário e cores

#### 3. Atividade Livre (15 min)
- Cada aluno cria seu próprio programa usando os blocos aprendidos
- Incentive a exploração: "O que acontece se mudar o número?"

#### 4. Compartilhamento (5 min)
- Alunos mostram suas criações para a turma
- Discussão: "O que você descobriu?"
