## 📖 Sobre o repositório

Material didático de **Scratch** para ensino de **Lógica de Programação** de forma visual e lúdica. Contém descrições de projetos, roteiros de atividades e links para os projetos online.

---

## 🗂️ Estrutura do Repositório

```
.
├── 01-introducao/              # Movimento, aparência, sons, eventos
├── 02-condicionais-e-loops/    # Se-então, repita, variáveis
├── 03-jogos/                   # Pong, labirinto, quiz interativo
├── 04-animacoes/               # Histórias interativas e animações
└── roteiros/                   # Roteiros de aula passo-a-passo
```
