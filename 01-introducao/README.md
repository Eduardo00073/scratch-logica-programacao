# 01 — Introdução ao Scratch

## Objetivos
- Conhecer a interface do Scratch
- Mover sprites pela tela
- Usar blocos de aparência e som

## Exercícios

### Exercício 1: Meu Primeiro Sprite
1. Abra o Scratch e escolha um sprite (personagem)
2. Use o bloco `mova 10 passos` para movimentá-lo
3. Adicione o bloco `quando bandeira verde clicada` para iniciar

### Exercício 2: Animação Básica
1. Use `sempre` para criar um loop infinito
2. Dentro do loop, alterne entre fantasias com `próxima fantasia`
3. Adicione `espere 0.5 segundos` entre as trocas

### Exercício 3: Sons
1. Escolha um som na aba "Sons"
2. Use o bloco `toque o som` quando o sprite for clicado
3. Experimente `toque o som até terminar` para diferentes efeitos
