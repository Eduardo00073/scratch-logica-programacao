# Politica de Seguranca

Este repositorio (scratch-logica-programacao) e um guia didatico de logica de programacao com Scratch, usado em aulas para criancas e adolescentes, mantido por Eduardo Junior.

## Reportando um problema

Se encontrar algum conteudo inadequado ou problema nos materiais didaticos, abra uma issue explicando o contexto.

## Boas praticas recomendadas

- Mantenha o conteudo adequado para o publico infanto-juvenil.
- Nao inclua links externos sem verificar a seguranca do destino.
- Revise os exemplos periodicamente para garantir que estejam atualizados.
