# 02 — Condicionais e Loops

## Objetivos
- Usar blocos `se/então` e `se/então/senão`
- Criar loops com `repita` e `sempre`
- Trabalhar com variáveis e entrada do usuário

## Exercícios

### Exercício 1: Verificador de Idade
1. Crie uma variável chamada `idade`
2. Use `pergunte "Qual sua idade?"` para obter entrada
3. Armazene a resposta na variável
4. Use `se idade >= 18 então` para verificar maioridade
5. Mostre mensagem: "Maior de idade" ou "Menor de idade"

### Exercício 2: Contador
1. Crie uma variável `contador` = 0
2. Use `repita 10 vezes`
3. Dentro do loop: incremente o contador e mostre na tela
4. Adicione `espere 1 segundo` entre incrementos

### Exercício 3: Tabuada
1. Pergunte ao usuário um número
2. Use `repita 10 vezes` com um contador de 1 a 10
3. Mostre: "número x contador = resultado"
